# Network GitOps & DNS Infrastructure

Репозиторий для управления гео-распределенной сетевой инфраструктурой домашнего дата-центра через **K3s**, **wg-easy (WireGuard)** и **dnsmasq**. 

Конфигурация приватной сети полностью зашифрована военным уровнем криптографии (AES-256/PGP) с помощью утилиты [SOPS: Secrets OPerationS](https://github.com/getsops/sops) и может безопасно храниться в этом публичном репозитории.

Управление всей инфраструктурой (как VPS, так и домашними нодами) происходит через единый интерактивный TUI-загрузчик с консольными чекбоксами `setup.sh`.

## 👥 Инструкция для разработчиков (Рабочий ПК / WSL)

Каждый участник команды должен один раз настроить свое рабочее окружение.

### 1. Установка утилит
Выполните в терминале WSL (Ubuntu/Debian) или Linux следующие команды для установки базовых пакетов и утилиты SOPS (актуальные версии бинарников для других платформ всегда доступны на [странице релизов getsops/sops](https://github.com/getsops/sops/releases)):

```bash
sudo apt update && sudo apt install gnupg curl -y

# Скачивание стабильного бинарника SOPS v3.13.3
curl -LO https://github.com/getsops/sops/releases/download/v3.13.3/sops-v3.13.3.linux.amd64

# Перемещение бинарника в системный PATH
sudo mv sops-v3.13.3.linux.amd64 /usr/local/bin/sops

# Предоставление прав на исполнение
sudo chmod +x /usr/local/bin/sops
```

### 2. Генерация PGP-ключа безопасности
Создайте личный ключ. **Важно:** когда утилита попросит придумать пароль (Passphrase), **ничего не вводите и нажмите Enter дважды**. Ключ должен быть абсолютно без пароля, чтобы автоматические Git-фильтры могли шифровать данные в фоновом режиме.

```bash
gpg --generate-key
```

### 3. Получение отпечатка (Fingerprint)
Найдите отпечаток созданного ключа (длинная 40-символьная строка из букв и цифр в секции `pub`):

```bash
gpg --list-secret-keys --keyid-format LONG
```
*Скопируйте полученную строку и передайте её владельцу репозитория для добавления в `.sops.yaml`.*

### 4. Настройка гит-фильтров (Выполнить внутри папки проекта)
Привяжите фильтры автоматического шифрования к вашему локальному Git. Это позволит прозрачно редактировать файлы как обычный текст — шифрование при `push` и расшифровка при `pull` будут происходить незаметно:

```bash
git config filter.sops.clean "sops --encrypt --input-type binary --filename-override private-hosts.enc /dev/stdin"
git config filter.sops.smudge "sops --decrypt --input-type binary /dev/stdin"
git config filter.sops.required true
```

## 🔐 Управление ключами и обновление доступа

### Как добавить нового пользователя или узел в команду:
1. Откройте файл `.sops.yaml` в корне проекта.
2. Допишите отпечаток нового PGP-ключа в секцию `pgp` через запятую:
   ```yaml
   creation_rules:
     - path_regex: \.enc$
       pgp: "ВАШ_ОТПЕЧАТОК,ОТПЕЧАТОК_КОЛЛЕГИ"
   ```
3. Выполните команду принудительного обновления ключей в терминале, чтобы перешифровать файл под новый состав участников:
   ```bash
   sops updatekeys private-hosts.enc
   ```
4. Закоммитьте изменения и отправьте обновленный файл в репозиторий:
   ```bash
   git add .sops.yaml private-hosts.enc
   git commit -m "Refactor: добавлен новый ключ доступа к приватной сети"
   git push origin master
   ```

## 🌐 Развертывание инфраструктуры (VPS и домашние ноды)

Все компоненты устанавливаются через **единый интерактивный загрузчик**. На серверах VPS и домашних нодах гит-фильтры не требуются — запуск происходит по Pull-модели напрямую из GitHub.

### 1. Запуск единого TUI-инсталлятора
Зайдите на целевую машину (VPS, Atom, Xeon, i5) под пользователем `root` (или через `sudo bash`) и запустите скрипт. Использование пайпа `| bash` исключено, так как интерактивным модулям внутри установщика требуется монопольный доступ к терминалу для работы с клавиатурой и буфером обмена:

```bash
# Скачивание главного загрузчика во временную директорию
curl -s -L "https://raw.githubusercontent.com/dma-cloud/environment/refs/heads/master/setup.sh" -o /tmp/setup.sh

# Назначение прав на исполнение и запуск интерактивного меню
chmod +x /tmp/setup.sh
sudo /tmp/setup.sh
```

### 📦 Описание доступных модулей внутри меню:

* **Инициализация DNS-сервера (dnsmasq + SOPS) на VPS**
  Устанавливает окружение на сервере, настраивает Split-Horizon DNS и запрашивает приватный PGP-ключ.
  *Инструкция по импорту ключа:* Выведите ключ в WSL (`gpg --export-secret-keys --armor ВАШ_ОТПЕЧАТОК`), скопируйте блок текста, вставьте его в окно терминала VPS и нажмите **Enter**, а затем **Ctrl+D**.
  
* **Настройка WireGuard туннеля (Split Tunneling + MTU)**
  Устанавливает WireGuard-tools, делает паузу для вставки конфига из админки `wg-easy`, после чего автоматически оптимизирует его: жестко выставляет безопасный Split Tunneling (`AllowedIPs = 10.50.0.0/24`) и подгоняет `MTU = 1360` под особенности домашних 4G-модемов.
  
* **Создание SWAP-файла на SSD (для слабых серверов)**
  Интерактивно запрашивает нужный объем (по умолчанию 16 ГБ), разворачивает файл подкачки на SSD, прописывает его в `/etc/fstab` и оптимизирует `vm.swappiness=10` для разгрузки процессоров класса Intel Atom и продления жизни диску.

### 2. Настройка автоматической синхронизации DNS (Только для VPS)
После первичного прогона пункта №1 в инсталляторе, на VPS создается скрипт автоматизации по пути `/opt/dns-sync/sync-dns.sh`. Добавьте его вызов в системный планировщик `crontab -e` для автоматической проверки изменений в Git каждые 5 минут:
```text
*/5 * * * * /opt/dns-sync/sync-dns.sh >> /var/log/dns-sync.log 2>&1
```
